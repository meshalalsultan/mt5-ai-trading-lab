# قوالب التوثيق بالعربية

[العودة للدليل](README.md)

انسخ القسم المناسب واملأه بما حدث فعلًا. اكتب «غير منفذ» أو «غير متاح» بدل تخمين نتيجة. القوالب الإنجليزية باقية لمن يحتاجها للعرض المهني.

## قالب تجربة

- **رقم التجربة وعنوانها:**
- **التاريخ وحالة التنفيذ:**
- **الهدف:** السؤال الذي نريد الإجابة عنه.
- **الاستخدام المهني:** من قد يستفيد ولماذا؟
- **الفرضية:** ما المتوقع قبل الاختبار؟
- **معيار النجاح:** كيف سنحكم على النتيجة؟
- **البيئة:** إصدار المنصة والنموذج والبيانات والفترة والمنطقة الزمنية والصلاحيات.
- **نص الطلب ورقم نسخته:**
- **الرد الفعلي ومكان حفظه:**
- **الأدلة وطريقة التحقق:**
- **ما نجح:**
- **ما فشل:**
- **القيود والمجهولات:**
- **النتائج:** نفصل الحقيقة عن الاستنتاج.
- **القيمة للشركة أو المتداول:** احتمال أم فائدة قسناها؟
- **فرصة منتج أو خدمة:**
- **الحكم النهائي:** نجاح ضمن نطاق / فشل / غير حاسم / مغلق بحدود.
- **الخطوة التالية:**

## قالب تقرير اليوم

- **اليوم والتاريخ:**
- **هدف اليوم:**
- **التجارب المرتبطة:**
- **ما أنجزته فعلًا:**
- **ما بقي أو تعطل:**
- **أهم ما تعلمته ودليله:**
- **الأخطاء والقيود:**
- **المخرج المحفوظ:** طلب / كود / تقرير / دراسة حالة / محتوى.
- **المهارة التي أظهرتها:**
- **الفائدة المهنية أو للشركات:**
- **فرصة منتج أو محتوى:**
- **العملاء المحتملون والإيراد:** القيم الفعلية مع مصدرها، أو «غير مسجل».
- **هل حدّثت الملفات والمهمة؟**
- **مهمة الغد وخطوتها الأولى:**

## قالب التقرير الأسبوعي

- **الفترة وروابط الأيام:**
- **أهم النتائج المدعومة:**
- **عدد التجارب المنفذة:** لا نحسب المخطط لها.
- **عدد التجارب التي تحققت معاييرها:**
- **نسخ الطلبات المختبرة والأدوات المختبرة:**
- **ما أصبح صالحًا للعرض المهني؟**
- **قدرات المساعد وحدوده التي شاهدناها:**
- **المهارات المكتسبة وأدلتها:**
- **أفكار الشركات والمنتجات:** أفكار أم تجارب مع عملاء؟
- **تفاعل المحتوى والإيرادات إن توفرت بيانات:**
- **ما نوقفه أو نغيره ولماذا؟**
- **ثلاث أولويات للأسبوع القادم ومعيار إنجاز كل منها:**

## قالب دراسة حالة

- **العنوان ورقم الحالة:**
- **المشكلة والسياق:**
- **دورك الشخصي بالتحديد:**
- **المدخلات والبيئة والحدود:**
- **ما فعلته ولماذا اخترت هذه الطريقة؟**
- **النتيجة الفعلية مقابل المرجع:**
- **الأدلة وروابط التجارب:**
- **الأخطاء والبدائل والقيود:**
- **الفائدة المقاسة:** افصلها عن المتوقع.
- **طريقة إعادة العرض أو الاختبار:**
- **الاستخدام المحتمل للشركات والخطوة التالية:**

لا نحول فكرة إلى دراسة نجاح دون نتيجة موثقة.

## قالب نسخة Prompt

- **الاسم ورقم النسخة:**
- **اللغة:** عربي / إنجليزي.
- **الحالة:** مسودة / منفذ / تحقق ضمن نطاق / متقاعد.
- **الهدف والبيانات المطلوبة:**
- **النموذج والإعدادات:**
- **النص الكامل القابل للنسخ:**
- **شكل الرد المتوقع:**
- **الحدود:** ما الممنوع تخمينه أو تنفيذه؟
- **رقم التجربة والتشغيل:**
- **ما تغير عن النسخة السابقة ولماذا؟**
- **كيف اختبرنا أثر التغيير؟**
- **النتيجة ودليلها:**

لا نغير نص نسخة اختُبرت ثم نحتفظ بالرقم نفسه. نص جديد أو ترجمة منفذة = نسخة موثقة جديدة.

## قالب مهمة على GitHub

- **العنوان:** رقم التجربة + هدف مختصر.
- **المطلوب:** المخرج المحدد.
- **معيار الإنجاز:**
- [ ] تجهيز البيئة.
- [ ] تنفيذ الاختبار.
- [ ] حفظ الرد والأدلة.
- [ ] التحقق وتسجيل الأخطاء.
- [ ] تحديث التقرير.
- [ ] اختيار الحكم النهائي والخطوة التالية.

الحالات: مؤجل ← مهمة اليوم ← اختبار ← توثيق ← مكتمل. «مرشح لمنتج» مرحلة اختيارية وليست شرطًا لكل تجربة.
