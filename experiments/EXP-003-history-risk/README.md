# EXP-003 — سجل التداول والمخاطر: تمرين بيانات اصطناعية

**الحالة: مخطط له، لم يُنفذ.** هذه المرحلة الثالثة من الخطة. لا توجد صفقات فعلية متاحة، لذلك نختبر دقة الحساب على مثال تعليمي معروف، دون إنشاء تداولات أو ادعاء تحليل حساب حقيقي.

## الهدف
اختبار فصل التمويل عن نتائج التداول، وحساب النتائج الصافية والتراجع من الرصيد، والامتناع عن استنتاج مخاطر غير مدعومة.

## Test A — قراءة المثال وتصنيفه
استخدم نص الطلب التالي فقط في البداية. لا تحسب المؤشرات حتى نراجع الفصل بين المدخلات.

```text
ابدأ EXP-003 — Test A: فهم بيانات اصطناعية.

هذه بيانات تعليمية مُنشأة يدويًا، ليست سجل حساب أو نتيجة استراتيجية. استخدم النص فقط، ولا تستدعِ أدوات المنصة أو تنفذ صفقات أو تغيّر إعدادات.

الحالة الابتدائية الاصطناعية: رصيد افتتاحي قبل الأحداث = 1000 وحدة نقدية، ولا توجد مراكز مفتوحة. يوجد إيداع إضافي +200 قبل الصفقة T04 مباشرة.

كل صف أدناه يمثل صفقة مكتملة واحدة، مرتبة حسب الإغلاق، وغير متداخلة. لا توجد تجزئة إغلاق. القيم رسوم وأرباح موقعة؛ لا توجد رسوم أخرى. لا يفترض وجود أسعار أو أحجام أو بيانات مراكز غير مذكورة.

id,gross_profit,commission,swap,fees
T01,100,-5,0,0
T02,-60,-5,0,0
T03,0,-5,0,0
T04,80,-5,-2,0
T05,-40,-5,0,0
T06,50,-5,0,0

نفذ فقط:
1. أكد أن المثال اصطناعي.
2. افصل الرصيد الافتتاحي والإيداع عن سجلات التداول.
3. اذكر عدد الصفقات وعدد أحداث التمويل الإضافية.
4. اشرح أن صافي الصفقة يساوي مجموع gross_profit وcommission وswap وfees بإشاراتها.
5. بيّن لماذا لا تعني gross_profit=0 بالضرورة صفقة متعادلة صافيًا.
6. اذكر البيانات الناقصة لتقييم الرافعة والهامش والتعرض وEquity Drawdown أثناء الصفقات.
لا تحسب إجمالي الأداء أو تصنف جودة استراتيجية. أجب بالعربية.
```

## Test B / C — لاحقًا
بعد مراجعة A نحسب النتائج الصافية، معدل الفوز بتعريفه، متوسط النتائج، Profit Factor والتراجع المطلق من منحنى الرصيد مع بيان معالجة الإيداع. ثم ندقق الحساب مقابل مرجع مستقل.
لا نساوي تراجع الرصيد بتراجع Equity أثناء المراكز المفتوحة. التنفيذ والنتائج ما زالا غير مسجلين.
