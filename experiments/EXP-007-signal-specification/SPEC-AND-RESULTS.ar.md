# EXP-007 — المواصفات والاختبارات المرجعية
التاريخ: 2026-09-23. النطاق المغلق: إشارة تعليمية، لا استراتيجية تداول كاملة.

## المواصفة v0.1
الرمز المستهدف لاحقًا XAUUSD والإطار H1. متوسط بسيط SMA20 على Close بإزاحة 0.
C1 آخر شمعة مغلقة، C2 السابقة لها، C21 الأقدم في النافذة المطلوبة.
- SMA1 = متوسط C1..C20؛ SMA2 = متوسط C2..C21.
- صعود: C2 ≤ SMA2 وC1 > SMA1.
- هبوط: C2 ≥ SMA2 وC1 < SMA1.
- بيانات سليمة مع عدم تحقق أي الاتجاهين: لا إشارة.
- بيانات ناقصة أو غير صالحة: تعذّر التقييم، دون تعويض بقيم مفترضة.
- يلزم 21 إغلاقًا مغلقًا صالحًا. لا تدخل الشمعة الجارية.
- التقييم عند اكتشاف شمعة جارية جديدة، على آخر شمعة مغلقة؛ لا افتراض تنفيذ بسعر الإغلاق.
- فجوات جلسات السوق ليست تلقائيًا فقد بيانات؛ لا ننشئ شموعًا صناعية لملئها.

## منع التكرار
المفتاح = الرمز + الإطار + وقت افتتاح الشمعة المغلقة المقيّمة.
النتيجة الصالحة، بما فيها «لا إشارة»، تسجل المفتاح مكتملًا. التكرار: «تجاهل: سبق التقييم».
التقييم المتعذر لا يكمل المفتاح؛ تجوز إعادة المحاولة بعد توفر البيانات.
هذه مواصفات منطقية؛ لم يُختبر تخزين الحالة أو إعادة تشغيل مؤشر بعد.

## سجل المراجعة A/B/C
A: القواعد واحتياج 21 إغلاقًا صحيحان. ثُبت الفصل بين تعذّر التقييم وعدم وجود إشارة، وبين شمعة جديدة وقرار تنفيذ صفقة.
B: التصنيفات صحيحة، لكن اشتقاق J احتوى خطأ جبريًا وسيطًا.
C: صحح الاشتقاق دون تغيير النتيجة. صُححت أيضًا عبارة توحي بتحقق الاتجاهين معًا، وكلمة دخيلة في وصف عدم إعادة التسجيل.

الاشتقاق المعتمد:
SMA1 = (1899/19 + 1899) / 20
= (1899 + 36081) / 380
= 1899/19 = C1.
استبدال العدد 1899 بالكسر 1899/19 في السطر السابق خطأ جبري، وليس مجرد تنسيق.
