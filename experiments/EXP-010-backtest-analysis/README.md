# EXP-010 — تحليل نتائج الاختبار التاريخي

**الحالة: مخطط؛ لم يُنفّذ.** خطوة الخطة التالية: تحليل النتائج (المهمة 13) بعد اختبار التكامل المحدود. لا استراتيجية جديدة ولا Optimization.

## Test A — جرد البيانات
استخدم تقرير Run 2 وأدلته المجمدة من EXP009 R5، قراءة فقط. أنشئ جدولًا للصفقات الأربع يضم: معرّف المركز، أوقات واتجاه الدخول، الحجم، أسعار الدخول والخروج، profit/commission/swap/fees إن توفرت، وسبب الخروج بدليله. افصل آخر إغلاق END OF TEST عن الإغلاقات الثلاثة الاستراتيجية. لا تستنتج تكلفة صفرية من حقل غائب؛ لا تعدّ الإيداع صفقة.

## Test B — مطابقة النتائج
بعد نجاح A، احسب الصافي من الحقول المتاحة وطابقه مع التقرير وتغير الرصيد بعد فصل التمويل. اشرح أي فرق دون تعويض مفترض. لا تستخرج Equity Drawdown من صفقات الإغلاق وحدها.

## Test C — حدود الاستنتاج
دقق الحسابات والفصل بين الإغلاقات؛ أربع صفقات لا تثبت الربحية أو المتانة. احتفظ بالفترة والحجم والقواعد؛ لا إعادة اختبار ولا تحسين لتجميل النتيجة.

## الطلب الجاهز الآن
ابدأ EXP-010 Test A فقط: اجرد تقرير التكامل الثاني المجمد لـEXP-009 R5 وأدلته، دون كود أو تشغيل أو تعديل. اعرض الصفقات الأربع والحقول المذكورة أعلاه مع مصدر كل حقل، ووسم المفقود غير متاح، ثم قرر هل تكفي البيانات للمطابقة الحسابية في Test B. لا تحسب الأداء الكلي في A ولا تدّعِ ربحية.
