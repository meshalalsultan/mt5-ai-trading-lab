# ابدأ هنا — إعداد جلسة التداول مع Mask Trader
**SESSION v0.1 | مسودة جاهزة لتجربة استخدام أولى، وليست منتجًا معتمدًا أو مطروحًا للبيع.**

## 1. ما الذي ستحصل عليه؟
ورقة واحدة تنظم سياق السوق، علاقة الأطر، شروط المراقبة، وما ينقص من بيانات، ثم مراجعة لاحقة منفصلة. لا تحتاج برمجة.
الحزمة لمن يعرف أساسيات الشارت؛ لا تشرح أساسيات التداول ولا تضمن وصول المساعد إلى بيانات المنصة. لم يُقَس بعد أثرها على الوقت أو جودة استخدام المتداول.

### جهّز ثلاثة أشياء
- رمز واحد وغرض محدد: مثل "فهم السياق وتجهيز قائمة مراقبة".
- H4/H1/M15 إن كانت متاحة؛ يمكن البدء بأقل مع إعلان حدود المقارنة.
- بيانات واضحة: قراءة متاحة للمساعد، أو صور يظهر فيها الرمز والإطار والمحور الزمني والسعري، أو جدول موثوق. أزل أي معلومات حساب شخصية. بيّن توقيت المصدر؛ لا تحوّله إلى توقيت آخر بالتخمين.

## 2. أول استخدام
1. افتح محادثة جديدة في مساعد MT5، وأرسل **الطلب 1** بعد ملء الحقول. إن كنت تستخدم صورًا أرفقها معه.
2. إذا طلب بيانات ضرورية، أجبه مرة واحدة. إذا أكد توفر البيانات تابع.
3. أرسل الطلبات **2 ثم 3 ثم 4 ثم 5** في المحادثة نفسها. هذه خطوات الحزمة، وليست أسئلة متابعة إضافية تُحسب ضدها.
4. احفظ ورقة الجلسة الناتجة مع بياناتها. قراءة الورقة واتخاذ أي قرار يبقيان مسؤوليتك؛ الحزمة لا تنفذ عمليات.
5. لاحقًا، عند توفر بيانات أحدث، أرسل **الطلب 6** مع الورقة والبيانات الجديدة.

لا تحتاج تركيب مؤشر أو EA أو تغيير إعدادات. لا يوجد زمن إنجاز مثبت؛ نسجل الزمن في الاستخدام الأول بدل الإعلان عن توفيره.

## 3. عندما لا تتوفر البيانات
| الحالة | الإجراء البسيط |
|---|---|
| المساعد لا يستطيع قراءة المنصة | أرفق صورًا أو بيانات؛ لا تطلب منه إصلاح الاتصال أو كتابة أداة |
| صورة لا تُظهر رقمًا بوضوح | استخدم وصفًا دون رقم أو أرفق صورة أوضح |
| إطار غير متاح | أكمل الوصف المتاح؛ لا تدّع مقارنة كاملة |
| أوقات الصور مختلفة | اذكرها منفصلة؛ لا تُقدَّم كلقطة متزامنة |
| أخبار غير متاحة | يبقى أثر الأخبار غير مقيم، لا تُختلق أحداث |
| لا توجد بيانات لاحقة | احفظ الورقة، وأجّل المراجعة |
| المساعد جازم بلا دليل | استخدم الطلب 4؛ إن بقي خطأ مؤثر فلا تعتمد المخرج |

## ما الذي يجعل الطلب مفيدًا؟
المقارنة بين الأطر، وضوح الشرط وتوقيت البيانات، والتمييز بين وصف السوق وتفسيره. كثرة الكلمات أو لقب "احترافي" ليسا معيارًا.

## حالة النسخة
النصوص والقوالب مكتوبة؛ المثال مؤلف اصطناعيًا وموسوم بذلك. لا رد منصة فعلي أو تجربة مستخدم محفوظة بعد. الطلبات 1–6 جديدة ومستقلة عن U1/U2/U3 القديمة. نراجع استخدامًا واحدًا طبيعيًا قبل استكمال العرض التجاري.
