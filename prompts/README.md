# Versioned prompt library

Prompts are research artifacts. A prepared prompt is not a tested or validated prompt.

| Category | Purpose |
|---|---|
| [account-analysis](account-analysis/README.md) | Data access and account diagnostics |
| [market-analysis](market-analysis/README.md) | Market context and multi-timeframe research |
| [strategy-development](strategy-development/README.md) | Explicit strategy specifications |
| [mql5-development](mql5-development/README.md) | Indicator/EA requirements, implementation and review |
| [strategy-tester](strategy-tester/README.md) | Test design, result analysis and robustness |

Use [TEMPLATE.md](TEMPLATE.md). Keep previously tested versions immutable. Increment v0.1 → v0.2 for experimental revisions; reserve v1.0 for a defined scope that passes documented acceptance checks. Record the exact changed wording and reason; version numbers alone prove nothing.
